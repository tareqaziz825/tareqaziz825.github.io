How the system works

Your stylesheet doesn't use named colours in components. It uses a "stock" model — a panel declares which coloured paper it is printed on, and four tokens rebind. Every palette below is expressed in that same vocabulary, so swapping one is a token change, not a rewrite.

--ground
The page behind everything. Nothing is printed directly on it.
--stock / tint
The vivid version of a colour. Card heads, badges, active nav.
--deep
The muted version. Used for full-page sheets, so the vivid cards inside still read as the loudest thing.
--on-stock / --on-deep
The text colour that belongs to each. Never chosen per component.

Working

The stock model is genuinely good architecture — colour lives in four tokens, not scattered through components. Contrast is strong everywhere; nothing fails AA. The six-colour coding makes the site memorable.

Against you

The accents come from a neon base (#ff0080, #0033ff, #aaff00) and sit at uneven lightness, so Blog shouts and Projects mutters. To an ML hiring manager the overall read is student project rather than practitioner.

Unused

Teal is fully defined in the token set and assigned to no page. The hero, header and footer all use the same neutral stock, so the landing page has no identity of its own.

02

Proposal A — Instrument

Keeps the brutalist structure, disciplines the colour. Every accent is pulled to the same perceived lightness and chroma, so the six pages read as one family instead of six moods. Neutrals shift slightly cool — the register of measurement equipment rather than paper forms.

Keeps

The structure you already built — thick edges, hard shadows, flat colour, mono labels. A visitor who saw the old site still recognises this one.

Changes

Accents are tuned to a narrow lightness band, so no page dominates. Minimum accent contrast rises from 5.46 to 6.56. Neutrals go cool, which separates the chrome from the warm accents.

Risk

Still a strong, opinionated look. If a reviewer dislikes brutalism, this does not rescue you — it executes the style properly rather than abandoning it.

03

Proposal B — Archive

The restrained direction. Hard edges give way to quiet hairlines and surface elevation; accents drop in saturation and stop flooding whole pages, acting as markers instead. The six-colour coding survives, but as a filing system rather than a paint job.

Keeps

Six-page coding, the stock token model, dark-only. Nothing in the HTML changes.

Changes

Borders drop from 6px to 1px and offset shadows disappear, so hierarchy comes from surface steps instead. This is a structural change, not only a colour one — --border-* and --shadow-* move too.

Risk

Safe reads as forgettable. This palette looks like competent product design; it no longer looks like you. Choose it if the portfolio's job is to not get in the way of the work.

Header, footer and hero

  • The chrome must not compete with the page coding. Header and footer appear on all eleven pages, and six of those pages carry a different accent. Colour the chrome and it either fights each page or forces one page's colour to own the whole site. Neutral chrome is what makes the accent mean you are on this page.
  • Your header now holds six coloured nav icons. That row is already the colour event in the masthead. A coloured background behind it would halve its legibility.
  • One change I do recommend: drop the footer to ground. Right now header and footer are the same value, so the page ends on the same note it opened with. Moving the footer to --ground lets it recede, while the header stays raised and reads as a fixed object. Keep the border so it still closes the page.

Hero — teal

  • Teal is already in your token set and no page uses it. Adopting it for the hero costs nothing, steals no section's identity, and finally gives the landing page a colour of its own — right now it shares the neutral stock with the header, footer and Connect panel, so the most important screen on the site is also the blankest.
  • It reads as instrumentation. Cyan-teal is the signal colour of oscilloscopes, terminals and plotting libraries. For an ML and computer-vision audience that is the right register — technical rather than corporate.
  • It sits opposite cobalt. Projects owns cobalt, and those are your two most-visited pages. Teal and cobalt are far enough apart in hue to be told apart instantly, close enough in temperature that the site still feels like one object.
  • Use it narrowly. Deep teal for the hero sheet, the bright tint for the eyebrow label and the Request resume button only. The portrait and the name stay neutral — the accent frames them, it doesn't tint them.

Cobalt was the other candidate, and it is the stronger "trustworthy technical" signal in isolation. I rejected it because Projects already owns it: repeating it on the landing page blurs the one navigational cue the six-colour system exists to provide.

05

What a switch actually costs

Instrument is a token-only change. Every value lives in the :root block of styles.css — around 40 lines. No HTML changes, no component changes.

Archive is tokens plus geometry: --border-hair, --border-card, --border-slab drop to 1–2px and the three --shadow-* tokens go to none or a soft blur. Still no HTML changes, but the site will look substantially different, and a few spacing values will want revisiting once the heavy borders are gone.

Header, footer and hero can be applied on their own, to the palette you already have, without committing to either proposal.

Contrast ratios calculated to WCAG 2.1 relative luminance. "Tint / on" is the accent against its own text colour; "Deep / on" is the page sheet against its body text.
